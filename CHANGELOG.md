# Changelog

## [2.0.0] - 2026-01-10

### Добавлено
- ✅ Поддержка PCA для снижения размерности эмбеддингов (256 → 128)
- ✅ Обработка оверлапов через параметры `step_size` и `duration`
- ✅ Метод `recognize()` для регистрации известных спикеров
- ✅ Режим `freeze` для использования только зарегистрированных спикеров
- ✅ Класс `Diarizer` для простого использования
- ✅ Функция `load_diarizer_from_config()` для загрузки из YAML
- ✅ Готовые конфигурационные файлы (4 варианта)
- ✅ Примеры использования для всех сценариев
- ✅ Подробная документация (README, QUICKSTART, MIGRATION_GUIDE)
- ✅ Метод `save_rttm()` для сохранения результатов
- ✅ Метод `get_speaker_map()` для получения маппинга спикеров

### Улучшено
- ✅ Метод `_get_start_end()` теперь поддерживает перекрывающиеся окна
- ✅ Метод `_process_diarization_segments()` для обработки оверлапов
  - Объединение соседних сегментов одного спикера
  - Разделение оверлапов разных спикеров по середине
- ✅ Улучшенная логика извлечения эмбеддингов для коротких сегментов
- ✅ Нормализация аудио в методе `run()`
- ✅ Правильная обработка тишины между сегментами

### Изменено
- ⚠️ Удалены зависимости от `streaming_nemo` (автономная библиотека)
- ⚠️ Класс `OnlineSpeakerPSDA` заменен на `Diarizer`
- ⚠️ API изменен для большей гибкости и удобства
- ⚠️ Параметры инициализации теперь принимаются напрямую (без config объекта)

### Исправлено
- 🐛 Исправлена обработка последнего сегмента в VAD
- 🐛 Исправлена обработка коротких сегментов после тишины
- 🐛 Исправлены импорты для автономной работы

### Документация
- 📖 Новый README.md с полным описанием
- 📖 QUICKSTART.md для быстрого старта
- 📖 MIGRATION_GUIDE.md для миграции со старой версии
- 📖 4 конфигурационных файла с комментариями
- 📖 4 примера использования

### Требования
- pyannote.core (для объекта Annotation)
- joblib (для загрузки PCA моделей)
- pydantic (для валидации конфигураций)

## [1.0.0] - Предыдущая версия

### Функциональность
- Базовая онлайн-диаризация через PSDA
- Простая обработка без оверлапов
- Класс `OnlineSpeakerPSDA`
